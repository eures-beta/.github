# Modèles communs Eures Beta

Ce dépôt public fournit le modèle de description des pull requests aux dépôts de l’organisation qui ne possèdent pas de modèle local.

👉 [Voir le modèle de description des pull requests](pull_request_template.md) pour découvrir les rubriques à remplir et les indications proposées.

Les agents doivent lire `pull_request_template.md` et remplir ses rubriques en français. Les consignes locales `AGENTS.md` renvoient vers cette source commune. Aucun secret ni détail de déploiement ne doit figurer ici.
