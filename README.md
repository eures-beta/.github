# Modèles communs Eures Beta

Ce dépôt public fournit le modèle de description des pull requests aux dépôts de l’organisation qui ne possèdent pas de modèle local.

👉 [Voir le modèle de description des pull requests](pull_request_template.md) pour découvrir les rubriques à remplir et les indications proposées.

Les agents doivent lire `pull_request_template.md` et remplir ses rubriques en français. Les consignes locales `AGENTS.md` renvoient vers cette source commune. Aucun secret ni détail de déploiement ne doit figurer ici.

## Images des descriptions de PR

Les captures utilisées seulement pour montrer un avant/après sont des **pièces
jointes GitHub**, téléversées depuis l’éditeur de description, et non des fichiers
à commiter. Attendre la fin du téléversement, conserver les liens générés et vérifier
le rendu de la description. Aucun commit, branche ou PR artificielle n’est requis.
Les ressources réellement nécessaires au produit ou à une documentation durable
restent versionnées lorsqu’elles font partie du travail demandé.

Le modèle commun porte cette consigne pour les auteurs humains et les agents des
dépôts qui l’utilisent. Les `AGENTS.md` des projets doivent continuer à demander sa
lecture avant chaque création ou modification de description. Un `AGENTS.md` dans
ce seul dépôt n’est pas automatiquement hérité par les autres dépôts de l’organisation.
