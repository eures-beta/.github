# Instructions du dépôt de modèles communs

Lire `pull_request_template.md` avant de rédiger ou de modifier une description de
PR, y compris via CLI/API. Les consignes de contenu communes à l’organisation vont
dans ce modèle et sont expliquées dans README.md ; ce fichier AGENTS.md s’applique
uniquement à ce dépôt, sans héritage automatique vers les autres dépôts.

Pour illustrer une PR, téléverser les captures de relecture comme pièces jointes
GitHub dans l’éditeur, puis insérer ses liens `github.com/user-attachments/...` dans
la description. Ne pas créer de commit, branche ni PR pour héberger ces images et
ne pas les ajouter au code. Seules les ressources produit/documentation durable
qui font réellement partie du changement demandé justifient des fichiers versionnés.

Si le connecteur/CLI ne sait pas joindre un fichier, utiliser l’interface GitHub ou
signaler la limite, sans contourner cette règle. Vérifier le rendu, la visibilité
pour les relecteurs et l’absence de données personnelles ou de liens de connexion
valides avant publication. Préserver les captures existantes lors d’une correction.
